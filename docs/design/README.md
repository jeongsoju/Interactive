# Interactive 디자인 기준 (시안 v1)

시안 이미지는 `mockups/`, 시안의 원본 HTML은 `source/`에 있다. 색·크기·간격은 아래 표가 기준이고, 표에 없는 값은 `source/`의 HTML 인라인 스타일에서 읽는다(1px = 1dp로 본다).
디자인 단계(progress.md 메모 참고) 전까지는 기능 화면을 만들 때 아래 "구조" 규칙만 지키고, 색·효과는 디자인 단계에서 입힌다.

## 구조

- 지도가 화면 전체를 채우고, 나머지 요소는 지도 위에 떠 있는 반투명(글래스) 카드다.
- 탭 4개(지도·기록·영토·설정)는 화면 아래 가운데의 알약 모양 막대 하나에 모은다. 아이콘 + 글자 라벨, 선택된 탭은 파란 배경.
- 가로형: P 카드·요약·동 상세는 왼쪽 패널(폭 600~640dp, 여백 40dp). 범례는 오른쪽 아래.
- 세로형: P 카드는 아래쪽 시트(좌우 여백 20dp, 탭 막대 위). 화면에는 핵심 하나만.
- 위 왼쪽: 기어 칩("P 주차 중 · 강릉 강문동"), 위 오른쪽: "내 영토 12곳" 칩.
- 동 상세가 열리면 탭 막대는 숨기고 패널을 위아래 40dp까지 늘린다.
- 지도 위 메모: 동 위에 프로필 원(64dp) + 그 위 말풍선(글자 22, 최대 폭 260dp). 선택된 동의 말풍선은 테두리 강조.

## P 카드 구성

1. 위 줄: 종류 칩(새로운 곳 / 추억 / 영토) + 동 이름·시각(보조 글자)
2. 제목 1줄(예: 처음 와본 곳이에요)
3. 본문 1~2줄
4. (처음 온 곳일 때) 머문 시간 진행 막대 + "머문 시간 4분 / 10분"
5. 버튼: 주 버튼(예: 영토 보기) + 닫기
