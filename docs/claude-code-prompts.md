## 2단계. 차량 데이터 통로 + 시연/직접 조작 모드

```
progress.md의 2단계를 시작할게. feature/vehicle-data 브랜치에서 해줘.
1. CLAUDE.md 5장대로 VehicleDataSource 인터페이스를 만들어줘. 기어, 위치, 누적 주행거리, 좌석 탑승 수를 시간에 따라 흘려보내는 구조로.
2. ReplayVehicleDataSource(시연 모드): assets의 JSON에 적힌 가짜 여행(강릉, 정차 3곳: 10분 미만 1곳, 10분 이상 2곳)을 재생해. 재생 속도 1배/10배/60배.
3. ManualVehicleDataSource(직접 조작 모드): 화면 버튼으로 기어(P/D/R)와 위치를 직접 바꿔 본다.
4. 앱을 켜면 모드 선택창(시연/직접 조작)을 띄우고, 고른 모드로 임시 화면에 기어·위치·주행거리·탑승 수를 글자로 보여줘.
5. 두 모드에서 값이 바뀌는 걸 캡처로 보여줘.
시작 전에 계획부터 짧게 보여줘.
```
